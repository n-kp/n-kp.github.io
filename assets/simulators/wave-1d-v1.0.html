補足

計算モデル

位置 x ∈ [0, 100]、波速 v = 10 仮想単位/s の一次元・線形・非分散モデルとした。波源A、Bをそれぞれ x = 20、80 に配置し、各波源から等振幅の波を左右へ伝播させた。波源は通過波を反射しない。

波源信号を sj(t) = aj(t) sin φj(t)、dφj/dt = 2πfj とし、uj(x,t) = sj(t − |x − xj|/v) を加算した。t < 0 の信号は0とした。初期位相は0、波長は λj = v/fj とした。周波数変更時も位相を連続させ、停止中も位相を進めた。

開始・停止および振幅変更時には、変更直前の振幅 a0 から目標振幅 a1 へ、a(τ) = a0 + (a1 − a0)[1 − cos(πτ/T)]/2（0 ≤ τ ≤ T）で移行させた。T = max[0.4 s, 1/(2f)] とし、変更時の周波数から定めた。移行終了後は目標振幅を維持した。

時間刻みは Δt = 1/120 s とし、各ステップで位相を 2πfΔt だけ更新した。波源信号は4096点の循環バッファーに保存し、遅延時刻の値を線形補間した。

境界条件

場の両端は無反射とした。反射面を x = 80 に置く場合、x ≤ 80 において u(x,t) = sA(t − |x − 20|/v) + R sA(t − (140 − x)/v) とした。固定端は R = −1（u = 0）、自由端は R = +1（∂u/∂x = 0）とし、x > 80 の場は0とした。反射面への透過・吸収は扱わない。

自由端型
位相変化なし		光の電場高屈折率側から低屈折率側への反射（ガラス→空気など）

光の例は垂直入射を前提とし、屈折率による分類は透明な非磁性媒質に限る。「固定端型」「自由端型」は電場の位相反転の対応を示し、反射振幅が入射振幅と等しいことを意味しない。実際の銀・アルミニウム鏡では複素屈折率と膜構造に応じて位相・振幅が変化し、厳密な固定端反射とは一致しない。
